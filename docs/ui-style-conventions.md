# 메인 화면 스타일

메인 화면 제목에는 `PageHeading`을 사용한다. `title`은 한글 화면명, `description`은 한두 문장의 설명, 자식 요소는 해당 화면의 주요 버튼이다. 세부 영역에는 h2/h3를 사용하고 메인 제목을 반복하지 않는다.

- 제목: 데스크톱 28px / 모바일 24px, 굵기 700, 짙은 중성색 `#39333f`.
- 설명: 13px, 줄 높이 1.7, 보조색 `#78717f`, 제목과 8px 간격.
- 제목 영역: 배경색 없이 하단 구분선 `#e5dfed`, 하단 여백 20px, 다음 콘텐츠까지 24px.
- 버튼: 높이 최소 40px, 13px, 모서리 9px. 기본 동작은 흰색 보조 버튼, 주요 등록·저장은 보라색 `#6f5a9f`.
- 모바일: 제목·설명 다음에 버튼을 배치하고 줄바꿈을 허용한다.
- 메인 제목 위 영문 장식 라벨은 사용하지 않는다. 성공·지연·취소 등 상태색은 콘텐츠 영역에서 유지한다.

`src/PageHeading.css`가 공통 정의다. 본인부담금 화면은 iframe 내부에서도 같은 CSS 원본을 주입하며 출력용 서식에는 적용하지 않는다. 화면별 CSS에 `.page-heading h1` 등의 재정의는 추가하지 않는다.
