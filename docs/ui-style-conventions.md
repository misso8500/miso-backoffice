# Miso Backoffice 디자인원칙서

## 업무 화면 설계

- 자주 하는 작업은 첫 화면에서 바로 시작할 수 있게 한다. 간단한 기록은 최소 입력과 기본 동작을 제공하고, 추가 입력과 이력은 원할 때 펼친다.
- 센터 실무자가 현재 상태를 확인하고 다음 행동을 선택할 수 있도록 화면을 구성한다. 수급자 목록, 계약 상태, 월간 라운딩처럼 비교가 중요한 화면은 기준일·선택 기간·상태·검색 범위를 명확히 표시한다.
- 기존 내비게이션, `PageHeading`, 날짜 입력, 표 입력 등 용도가 같은 공통 요소를 재사용한다. 목록은 비교에 필요한 요약 정보를 우선하고 상세 이력과 서류는 대상 화면에서 제공한다.
- 등록·저장 등 주요 행동을 구분하고, 조회 중·빈 결과·실패·저장 완료를 화면에서 식별할 수 있게 한다. 상태는 색상과 함께 텍스트로 표현하고, 키보드 이동과 포커스를 유지한다.
- 데스크톱 표와 입력 흐름을 우선 검증하고, 모바일에서도 주요 정보를 읽고 조작할 수 있는지 확인한다. 긴 이름, 넓은 표, 확대, 오류 메시지가 주요 행동을 가리는지 점검한다. 공유 화면의 민감 항목에는 기존 가림·열람 규칙을 적용한다.
- 조회 범위와 재조회 동작은 [개발원칙서의 데이터 조회·메모리 기준](development-principles.md#데이터-조회-병목과-메모리-관리)을 함께 따른다.

## 메인 화면 스타일

메인 화면 제목에는 `PageHeading`을 사용한다. `title`은 한글 화면명, `description`은 한두 문장의 설명, 자식 요소는 해당 화면의 주요 버튼이다. 세부 영역에는 h2/h3를 사용하고 메인 제목을 반복하지 않는다.

- 제목: 데스크톱 28px / 모바일 24px, 굵기 700, 짙은 중성색 `#39333f`.
- 설명: 13px, 줄 높이 1.7, 보조색 `#78717f`, 제목과 8px 간격.
- 제목 영역: 배경색 없이 하단 구분선 `#e5dfed`, 하단 여백 20px, 다음 콘텐츠까지 24px.
- 버튼: 높이 최소 40px, 13px, 모서리 9px. 기본 동작은 흰색 보조 버튼, 주요 등록·저장은 보라색 `#6f5a9f`.
- 모바일: 제목·설명 다음에 버튼을 배치하고 줄바꿈을 허용한다.
- 메인 제목 위 영문 장식 라벨은 사용하지 않는다. 성공·지연·취소 등 상태색은 콘텐츠 영역에서 유지한다.

`src/PageHeading.css`가 공통 정의다. 본인부담금 화면은 iframe 내부에서도 같은 CSS 원본을 주입하며 출력용 서식에는 적용하지 않는다. 화면별 CSS에 `.page-heading h1` 등의 재정의는 추가하지 않는다.
