# 직원 상담일지

**기관 운영 서류 업무 → 직원 상담일지**에서 예시 `tmp/직원상담일지_예시.png`의 구성에 맞춰 입력한다. 예시의 실제 이름·상담 내용은 초기 데이터로 등록하거나 공개 이미지로 복사하지 않는다.

## 작성·조회

1. ‘새 상담일지’를 눌러 서식을 연다. 명부는 기존 **근로계약 관리** 데이터를 사용한다.
2. ‘상담대상’에서 이름·직종·생년월일을 확인해 직원을 선택한다. 상담자도 기존 담당 직원 명부에서 선택하거나 이름·직책을 직접 입력할 수 있다.
3. 급여종류(방문요양/방문목욕), 상담일·시작/종료 시간, 상담방법(대면/유선), 조치일자를 서식 안에서 입력한다.
4. 상담내용, 조치 필요/불필요, 조치필요내용과 상단 확인자 이름을 기록하고 저장한다. 날짜에 따라 연도·분기 제목이 바뀐다.
5. 저장한 일지는 직원·직종·상담자 검색, 연도·분기 필터로 찾는다. 수정·보관·복원과 저장 이력 확인을 지원한다.
6. ‘인쇄·PDF’는 앱 메뉴와 입력 도구를 뺀 A4 서식을 인쇄한다. 브라우저에서 PDF로 저장할 수 있다.

상담대상과 상담일은 저장에 필요하다. 내용이 비어 있어도 저장할 수 있으며 목록에는 ‘내용 미입력’으로 표시한다. 내용 저장을 결재·상담 완료로 해석하지 않는다. 확인란은 이름을 기록하는 칸이며 전자결재 워크플로우를 만들지는 않는다. 조치일자는 상담일 이전으로 지정할 수 없고, 시간을 입력하면 시작·종료 둘 다 필요하며 종료가 시작보다 늦어야 한다.

## 직원 매핑

- 상담대상은 자유 입력한 이름 대신 **근로계약 ID**로 연결한다. 같은 이름의 다른 직원은 생년월일·직종과 계약기간으로 구분한다.
- 유효 길이의 주민번호 13자리가 같은 계약은 한 직원으로 묶는다. 주민번호가 없으면 이름만으로 합치지 않고 계약별로 유지한다. 주민번호 자체는 상담대상 명부 API에 포함하지 않는다.
- 상담일을 포함하는 계약을 먼저 선택하고, 없으면 그날 이전에 시작한 최근 계약, 그것도 없으면 가장 최근 계약을 제시한다. 화면에 연결 계약기간을 표시한다. 비활성 계약도 선택해 과거 상담을 기록할 수 있다.
- 저장할 때 서버가 실제 직원 이름·생년월일·직종·계약기간을 확인해 스냅샷으로 남긴다. 클라이언트가 보낸 이름이나 직종을 신뢰하지 않는다.
- 명부가 나중에 바뀌어도 기존 상담일지의 저장 당시 표시를 유지한다. 상담대상 계약을 바꾸면 새 대상의 정보로 연결한다. 과거 상담일지의 대상 ID나 명부 자체를 수정하지 않는다.

## 저장과 API

- `GET /api/work/staff-counseling/context`: 직원 계약 그룹·상담자 명부
- `GET /api/work/staff-counseling`: 내용 본문을 제외한 목록 요약
- `GET /api/work/staff-counseling/:id`: 서식 내용·저장 이력
- `POST /api/work/staff-counseling`, `PUT /api/work/staff-counseling/:id`: 작성·수정
- `POST /api/work/staff-counseling/:id/archive`: 보관·복원

기존 로그인·허용 계정 검사를 거친다. `work_staff_counseling`에 대상 계약 ID·상담일·서식을, `work_staff_counseling_events`에 버전별 내용과 작성자를 저장한다. 저장 요청 ID로 재시도 중복을 막고 버전 충돌 시 현재 입력을 보존해 다시 조회할 수 있게 한다. 서식과 이력은 하나의 트랜잭션으로 저장하므로 중간 실패 시 모두 취소한다.

SQLite는 API 시작 시 `server/staff-counseling-schema.sql`을 적용한다. PostgreSQL은 기존 `server/postgres/schema.sql` 부트스트랩에 포함하며 두 테이블에 RLS 및 anon/authenticated 직접 접근 차단을 설정한다. 최신 API 재시작 또는 배포가 필요하다.

- `tests/staff-counseling-ui.mjs`: 임시 API와 실제 PC/모바일 Chrome에서 서식 직접 입력, 날짜별 계약 매핑, 동명이인 선택, 미저장 보호, 저장·수정·충돌 복구·이력·검색/분기·보관/복원·새로고침·재시작과 인쇄 전용 서식/A4 PDF를 검증한다.
