# 수급자 유효보기 사용 안내

## 유효보기 열기

수급자 목록 위에서 **유효**를 누릅니다. 다음 내용을 왼쪽부터 확인합니다.

| 항목 | 확인하는 내용 |
| --- | --- |
| 계약 상태 | 현재 기관 이용기간 안인지, 만료됐는지, 시작 예정인지 |
| 기관 이용기간 | 우리 센터에서 서비스를 제공할 수 있는 현재 계약기간 |
| 등급 | 수급자 정보에 등록한 현재 등급 |
| 장기요양 인정기간 | 인정서에 적힌 서비스 이용 자격 기간 |
| 갱신예정일 | 인정 종료일 한 달 전의 확인 목표일 |
| 급여제공계획 | 현재 실행 중인 계획기간과 정기 작성·통보 마감 |

계약 중이라는 표시는 실제 요양보호사가 방문하고 있다는 뜻이 아닙니다. 기관 이용기간, 인정기간, 계획 실행기간은 각각 확인합니다.

갱신예정일은 기관 이용계약 만료일이 아니라 **인정서의 인정 종료일**로 계산합니다. 예를 들어 인정 종료일이 2028년 9월 8일이면 갱신예정일은 2028년 8월 8일입니다. 3월 31일처럼 이전 달에 같은 날짜가 없으면 이전 달의 마지막 날로 표시합니다.

## 이전 기간과 계약 기록 확인하기

1. 수급자 아래의 **기간·변경 이력 보기**를 누릅니다.
2. **장기요양 인정기간별 계획**에서 최근 인정기간부터 확인합니다. 해당 인정기간에 연결된 계획 실행기간, 작성일·통보일도 함께 보입니다.
3. **기관 이용계약 변경 이력**에서 이전 계약과 변경 후 계약을 비교합니다.
4. 다 봤으면 **기간·변경 이력 접기**를 누릅니다.

- 계약을 갱신한 기록은 **계약 갱신됨**으로 표시합니다.
- 오탈자를 고친 기록은 **계약 날짜 정정**으로 표시합니다. 새로운 계약으로 세지 않습니다.
- 재계약, 서비스 재개, 계약 종료, 비활성화 기록은 구분해서 표시합니다.
- 이전 날짜가 저장되어 있지 않으면 추정해서 표시하지 않습니다.
- 상세 정보나 이미지를 보려면 수급자 이름 또는 **상세 정보·서류 확인**을 누릅니다.

## 인정기간이 미등록으로 나올 때

수급자 상세 화면에서 인정서류 기간을 연결하거나, 급여제공계획 작성 화면에서 인정기간을 입력해 주세요. 기관 이용기간을 인정기간으로 복사하여 대신 표시하지 않습니다.

서류에 연결한 기간과 계획에 기록한 인정기간은 같은 날짜이면 하나로 묶어 보여줍니다. 당시 계획에 남긴 등급은 ‘계획 기록 등급’으로 표시하여 수급자 현재 등급과 구분합니다.

## 화면이 좁을 때

표를 좌우로 움직여 나머지 항목을 확인합니다. 읽기 어려울 정도로 글자와 버튼을 줄이지 않았습니다.

## 개발·운영 참고

- 목록 API에 이미지 원본이나 폴더 정보 대신 인정기간의 ID·시작일·종료일만 추가합니다.
- 인정기간 메타데이터는 DB에 저장된 연결 정보에서 조회합니다. 목록을 열 때 Drive 이미지 다운로드는 발생하지 않습니다.
- 계약 변경 이력은 펼칠 때 기존 인증된 이력 API에서 조회합니다. 실패 시 ‘다시 불러오기’를 제공합니다.
- 새로운 테이블이나 유료 저장소는 추가하지 않습니다.
- API 코드가 변경되어 로컬에서는 API 서버를 재시작해야 합니다. 배포 환경에서는 최신 코드를 재배포합니다.
- 기존 계약 등록 날짜는 기관 이용 시작일과 공유하는 데이터가 있으므로, 별도의 ‘최초 포털 입력일’이라고 표시하지 않습니다.
