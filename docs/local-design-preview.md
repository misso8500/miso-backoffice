# 로컬 백오피스 디자인 미리보기

수급자·근로계약 화면을 공동 업무 창구 시안과 같은 보라색 계열, 둥근 모서리, 부드러운 그림자로 정리했다.

## 적용 범위

- 사이드바: 220px 너비, 단순한 miso 로고, 흰색 활성 메뉴, 하단 계정 정보.
- 목록: 연보라 표 머리글, 둥근 외곽, 행 강조, 상태 배지, 검색·필터·보기 전환.
- 입력: 빠른 등록 카드, 둥근 입력창·버튼, 포커스 표시, 선택 항목 강조.
- 상세: 둥근 상세 패널, 연보라 요약 영역, 정보·근로조건·계약 이력 카드.
- 보조 화면: 다중 표 입력, 확인 대화상자, 문서 이미지 카드와 기간·계획 편집 영역.

업무 로직, 인증, API, 데이터 구조, 표의 열/필드 구성은 변경하지 않았다. 상태 경고색과 표 입력의 연속된 셀 경계는 유지한다. 모바일의 상세 패널은 화면 폭을 활용한다.

## 표시 조건과 코드

`src/App.tsx`에서 개발·운영 모두 `sidebar-preview` 클래스를 부여한다. 기존 파일명과 클래스명은 호환성을 위해 유지하지만, `src/dev-sidebar.css`와 `src/dev-workspace.css`는 이제 공통 서비스 테마로 사용한다. miso 로고, 메뉴, 하단 계정 정보와 화면 스타일은 운영 빌드에도 동일하게 적용한다.

Vite 개발 모드(`import.meta.env.DEV`)일 때만 화면 오른쪽 아래에 `DEV · 개발 환경` 표시를 별도로 노출한다. 운영 빌드에는 표시하지 않는다.

기존 로컬 서버 http://127.0.0.1:5173/ 에서 로그인 후 확인한다. 사이드바 메뉴 전환, 수급자 기본/계획/기간/연락처 보기, 근로계약 목록 및 이력, 등록/수정 패널과 다중 표 입력을 검토한다. 실제 데이터 수정 없이 화면을 열고 닫는 것으로 디자인을 확인할 수 있다.

## 검증

`npm run build`의 TypeScript 검사 및 Vite 빌드 통과. 개발 서버의 페이지와 스타일 파일 HTTP 응답 확인. 번들 크기 안내가 출력되지만 빌드는 성공했다. 실제 로그인 후 브라우저 렌더링과 모바일 시각 검증은 수행하지 않았다.
