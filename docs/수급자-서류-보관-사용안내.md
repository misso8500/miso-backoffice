# 수급자 서류 사진 보관 안내

수급자의 신분증과 장기요양 서류 사진을 구글 드라이브에 넣는 방법입니다.
컴퓨터에서 구글 드라이브를 열고, 아래 순서대로 따라 해 주세요.

> **지금은 서류를 보관하는 단계입니다.**
> 드라이브에 사진을 넣어도 업무 시스템의 수급자 화면에 자동으로 나타나지는 않습니다.
> 수급자와 서류를 연결하는 기능은 앞으로 추가될 예정입니다.
> 현재 업무 시스템의 ‘Drive 연결 테스트’는 연결 확인용입니다.

## 1. 먼저 준비해 주세요

- 서류가 있는 구글 드라이브를 사용할 수 있는 계정
- 수급자 본인의 신분증 사진
- 장기요양인정서 사진
- 개인별장기요양이용계획서 사진
- 복지용구확인서 사진

사진이 여러 장이면 모두 준비해 주세요. 지금 화면에서 사용할 수 있는 사진 파일은 **JPG, JPEG, PNG, WebP**입니다. 파일 이름 끝에 `.jpg`, `.jpeg`, `.png`, `.webp`가 붙어 있는지 확인하면 됩니다.

PDF나 한글 파일만 있다면 임의로 파일 이름 끝을 바꾸지 말고 담당자에게 문의해 주세요. 이름을 바꿔도 사진 파일로 바뀌지는 않습니다.

## 2. 수급자의 폴더를 열어 주세요

1. 인터넷에서 평소 사용하는 구글 드라이브를 엽니다.
2. **`1. 수급자 정보`** 폴더를 두 번 누릅니다.
3. 서류를 넣을 수급자의 이름이 적힌 폴더를 두 번 누릅니다.
4. **맞는 수급자의 폴더인지 한 번 더 확인합니다.**

같은 이름의 수급자가 두 명 있다면, 어느 폴더인지 담당자에게 먼저 확인해 주세요.

> 이전부터 보관한 파일은 그대로 두어도 됩니다.
> 기존 파일을 한꺼번에 옮기거나 이름을 전부 바꿀 필요는 없습니다.
> 새로 넣는 서류부터 아래 방법을 사용해 주세요.

## 3. 신분증을 넣을 폴더를 만들어 주세요

수급자의 폴더 안에서 진행합니다.

1. 왼쪽 위의 **`+ 새로 만들기`**를 누릅니다.
2. **`새 폴더`**를 누릅니다.
3. 이름에 **`공통서류`**를 입력합니다.
4. **`만들기`**를 누릅니다.

이미 `공통서류` 폴더가 있다면 새로 만들지 않고 그 폴더를 사용합니다.

**신분증은 이곳에 넣습니다.** 신분증은 인정 기간이 바뀌어도 같은 위치에서 확인하는 서류입니다.

## 4. 인정서류를 넣을 폴더를 만들어 주세요

수급자의 이름이 적힌 폴더로 돌아갑니다. 화면 위쪽의 폴더 경로에서 수급자 이름을 누르면 돌아갈 수 있습니다.

1. **`+ 새로 만들기` → `새 폴더`**를 누릅니다.
2. 이름에 **`인정서류`**를 입력하고 만듭니다.
3. 만든 `인정서류` 폴더를 두 번 눌러 엽니다.
4. 그 안에 **인정 기간 이름의 폴더**를 만듭니다.

### 인정 기간은 어디에서 확인하나요?

**장기요양인정서에 적힌 ‘인정 유효기간’**을 확인해 주세요.

예를 들어 인정서에 아래처럼 적혀 있다면,

**2026년 9월 9일 ~ 2028년 9월 8일**

폴더 이름은 다음과 같이 입력합니다.

```text
20260909~20280908
```

- 앞의 숫자는 시작일입니다.
- 뒤의 숫자는 종료일입니다.
- 날짜 사이에는 `~`를 넣습니다.
- 아래 날짜는 설명을 위한 예시입니다. 실제 인정서의 날짜를 사용해 주세요.

> **사진을 찍은 날짜나 센터 이용계약 날짜를 넣지 않습니다.**
> 인정서의 기간을 찾기 어렵다면 추측하지 말고 담당자에게 확인해 주세요.

## 5. 사진을 넣어 주세요

사진을 드라이브에 넣는 것을 **‘업로드’**라고 합니다.

### 신분증 사진 넣기

1. 수급자 폴더 안의 **`공통서류`** 폴더를 엽니다.
2. **`+ 새로 만들기` → `파일 업로드`**를 누릅니다.
3. 컴퓨터에 있는 신분증 사진을 선택합니다.
4. **`열기`**를 누릅니다.
5. 업로드 완료 표시가 나올 때까지 기다립니다.

수급자 본인의 신분증인지 확인해 주세요. 보호자의 신분증은 본인의 신분증과 섞지 말고 담당자에게 보관 위치를 확인해 주세요.

### 인정서류 사진 넣기

1. **`인정서류`** 폴더를 엽니다.
2. 해당 **인정 기간 폴더**를 엽니다.
3. **`+ 새로 만들기` → `파일 업로드`**를 누릅니다.
4. 아래 서류의 사진을 선택하고 **`열기`**를 누릅니다.

| 넣을 서류 | 넣을 위치 |
| --- | --- |
| 장기요양인정서 | 해당 인정 기간 폴더 |
| 개인별장기요양이용계획서 | 해당 인정 기간 폴더 |
| 복지용구확인서 | 해당 인정 기간 폴더 |

여러 장을 한 번에 선택하기 어렵다면 **한 장씩 넣어도 됩니다.**

## 6. 사진 이름을 알아보기 쉽게 바꿔 주세요

사진 이름이 `IMG_0001`이나 `KakaoTalk_…`이면 어떤 서류인지 찾기 어렵습니다. 새로 넣은 사진은 아래처럼 이름을 붙여 주세요.

| 서류 | 사진 이름 예시 |
| --- | --- |
| 신분증 | `신분증_01.jpg` |
| 장기요양인정서 | `장기요양인정서_01.jpg` |
| 이용계획서 첫 번째 장 | `개인별장기요양이용계획서_01.jpg` |
| 이용계획서 두 번째 장 | `개인별장기요양이용계획서_02.jpg` |
| 복지용구확인서 | `복지용구확인서_01.jpg` |

**이름을 바꾸는 순서**

1. 드라이브에서 해당 사진 위에 마우스를 놓습니다.
2. 마우스 **오른쪽 버튼**을 누릅니다.
3. **`이름 바꾸기`**를 선택합니다.
4. 서류 종류와 장 번호를 입력합니다.
5. 변경 내용을 저장합니다.

`01`, `02`, `03`은 서류를 읽는 순서입니다. 한 장이면 `01`만 쓰면 됩니다.

> 이름 끝의 `.jpg`, `.jpeg`, `.png`, `.webp`는 원래대로 두세요.
> 위 예시가 `.jpg`여도 원래 사진이 `.png`라면 `.png`를 유지합니다.
> 파일 이름에 주민등록번호 전체를 적지 않습니다.

## 7. 사진을 열어 확인해 주세요

업로드가 끝나면 사진을 두 번 눌러 확인합니다.

- 다른 사람의 서류가 아닌가요?
- 사진의 위쪽과 아래쪽이 모두 찍혀 있나요?
- 글자가 흐리지 않고 읽을 수 있나요?
- 여러 장인 서류가 빠짐없이 들어갔나요?
- `01`, `02`, `03` 순서가 맞나요?
- 인정서의 기간과 폴더 이름이 같은가요?

내용이 잘렸거나 흐리면 서류 전체가 보이도록 다시 촬영하거나 스캔해 주세요.

## 8. 나중에 새 서류를 받으면 이렇게 해 주세요

### 인정 기간이 바뀐 경우

`인정서류` 안에 **새 인정 기간 폴더를 추가**하고 새 서류를 넣습니다.

이전 인정 기간의 폴더와 사진은 그대로 둡니다. 예전 서류도 나중에 확인할 수 있어야 합니다.

### 같은 인정 기간의 정정 서류를 받은 경우

기존 사진을 지우거나 덮어쓰지 말고 새 파일로 넣어 주세요.

새 사진 이름에는 정정본임을 표시합니다. 예를 들면 다음과 같습니다.

```text
장기요양인정서_정정본_20261015_01.jpg
```

`20261015`에는 정정본을 받은 날짜를 적습니다. 담당자에게 정정 서류가 추가되었다고 알려 주세요.

## 완성된 폴더 모양

아래는 수급자 한 명의 예시입니다.

```text
1. 수급자 정보
└─ 수급자A
   ├─ 공통서류
   │  └─ 신분증_01.jpg
   └─ 인정서류
      └─ 20260909~20280908
         ├─ 장기요양인정서_01.jpg
         ├─ 개인별장기요양이용계획서_01.jpg
         ├─ 개인별장기요양이용계획서_02.jpg
         └─ 복지용구확인서_01.jpg
```

## 막히는 일이 있나요?

| 상황 | 이렇게 해 주세요 |
| --- | --- |
| 폴더를 만들거나 사진을 넣을 수 없어요. | 계정에 작업 권한이 있는지 담당자에게 확인해 주세요. |
| 같은 이름의 수급자가 있어요. | 서류를 넣기 전에 담당자에게 대상 폴더를 확인해 주세요. |
| 인정 기간을 모르겠어요. | 날짜를 임의로 적지 말고 인정서를 함께 확인해 달라고 요청해 주세요. |
| 같은 사진을 두 번 넣은 것 같아요. | 임의로 삭제하지 말고 담당자와 확인해 주세요. |
| 사진을 넣었는데 업무 시스템에 안 보여요. | 현재는 자동 연결 기능이 없습니다. 드라이브에 보관되었는지 먼저 확인해 주세요. |
| 다른 사람도 볼 수 있게 하려면 어떻게 하나요? | 공유 설정은 담당자에게 요청해 주세요. ‘링크가 있는 모든 사용자’로 바꾸지 않습니다. |
