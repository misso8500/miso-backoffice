# 아이디에이션 - 수급자 관련
## 수급자 관련 서비스 UX 여정 기획

### 1. 센터 내 수급자가 되는 과정
**1. 장기요양등급 신청을 위해 개인정보를 받는다.**
    - 주 고객이 된 상태는 아니지만, 단건 관리 혹은 주기 관리 대상이 됨
    - 수집 데이터
        - 수급자 이름
        - 수급자 나이
        - 수급자 주민번호
        - 수급자 주소지
        - 수급자의 병력
        - 수급자의 복용약 여부
        - 수급자의 현재 거주 상황
        - 보호자 이름
        - 보호자 관계
        - 보호자 전화번호
    - 연결되는 계약 혹은 문서는
        - 신규 장기요양 신청서
**2. 장기요양등급 선정되어 방문요양 계약 후 서비스를 실시한다.**
    - 주 고객 전환 대상. 서비스 시작부터 상시 관리 대상이 됨
    - 수집 데이터
        - 장기요양인정번호
        - 장기요양등급
        - 서비스 가능 항목(요양,간호,목욕,주간보호)
        - 장기요양 이용 시작일
        - 장기요양 이용 종료일
    - 연결되는 계약 혹은 문서
        - 센터 방문요양 계약서
        - 장기요양 3종 인정서류(인정서,개장계,복지용구)
        - 장기요양 급여제공계획서
**3. 매월 상태를 확인하고 기록한다.**
    - 매월 방문요양 서비스를 실시하는 고객. 서비스를 온전히 제공하기 위해 정보를 추적해야 함
    - 수집 데이터
        - 수급자 방문 업무수행일지
        - 수급자 상태변화기록지(파일)
        - 수급자 미전송 수기기록지(일자-사유)
        - 수급자 상담일지(파일)
4. 반기별로 수급자의 급여서비스계획을 검토한다.
5. 수급자의 장기요양 이용 갱신일을 확인하고, 갱신 서류를 제출한다.
6. 수급자의 욕구 혹은 사정으로 서비스를 해지한다.*
