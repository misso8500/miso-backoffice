# 공동 업무 창구 검토 시안

[화면 시안 열기](work-hub.html)

`work-hub.html`을 브라우저로 열면 별도 설치·서버·로그인 없이 사용할 수 있다. 날짜는 가상 사례가 있는 **2026-10-19**로 시작한다. HTML 파일이 문서로 열리면 브라우저에서 해당 파일을 연다.

이 시안은 Sites 스킬의 로컬 작업 지침을 참고한 독립 HTML이며 외부 게시하지 않았다. 기존 백오피스의 실행 진입점·API·DB와 불릿저널 원본은 수정하지 않았다. 데이터는 탭 메모리에만 있으며 새로고침/초기화 시 변경이 사라진다. 가상 인물·업무만 포함한다.

## 검토 순서

1. **빠른 추가:** 센터장 요청, 김 사회복지사 담당으로 업무를 추가한다. 시간이나 폴더를 먼저 정하지 않아도 저장된다. 보기 대상을 김 사회복지사로 바꾸어 나타나는지 확인한다.
2. **오늘:** 황 사회복지사 보기에서 급여계산에 수행을 남긴다. 계획과 실제가 나란히 보이고 업무 전체는 미완료로 유지되는지 본다.
3. **주간:** 기한·예정·실적을 구분해 본다. 날짜가 배치되지 않은 업무를 날짜/시간대 미정으로도 계획할 수 있다. 날짜를 누르면 해당 날짜 오늘 보기로 이동한다.
4. **월간:** 전체 구성원으로 바꿔 기한과 공동 라운딩 일정을 개괄한다. 같은 공동 일정이 참여자별로 중복 생성되지는 않는다. 확인 필요 수는 수행 기록의 내용·시간대 기준이며 근태/서류 전체 누락 수가 아니다.
5. **일지:** 황 사회복지사, 10월 19일로 돌아와 서류 → 업무수행일지를 연다. 급여자료 취합 항목의 실제 시간대를 지정하면 오전/오후에 반영된다. 내용 확인 체크는 수행 기록에만 적용된다.
6. **업무 전체 완료:** 일간 목록에서 명시적으로 완료한다. 이미 남긴 계획과 수행은 보존된다.

## 피드백 반영: 관련자·분류·날짜 이동·서류 연결

- 업무 추가에서 수급자/근로자를 이름·구분 정보로 검색하고 여러 명 연결할 수 있다. 없으면 이름과 선택적 구분 정보로 임시 등록한다. 동일 종류·이름·구분 정보는 기존 항목에 연결하며, 동명이인에게는 구분 정보 입력을 유도한다. 실제 백오피스 명부는 조회·수정하지 않는다.
- 센터 업무 분류를 선택할 수 있다. 수급자 관리, 서비스 관리, 인력 관리, 기관 운영, 권익·안전 관리는 **검토용 초안**이다. 빨리 입력할 때는 미분류로 남길 수 있다. 카드와 연결된 일지 검토 항목에서 분류·관련자를 확인한다.
- 일지 검토에서 이전/다음 날과 주간 날짜 띠로 이동한다. 월 경계를 넘어가며 직원과 일지 화면을 유지한다. 날짜별 수행 수·확인 필요 수가 표시된다.
- `서류` 메뉴와 각 화면 하단의 연결 카드로 출근부·업무수행일지·휴가계획/신청서의 관계를 드러낸다. 업무일지는 수행 기록에서 구성하고, 출근부는 월간 기록/휴가 예정과 별도로 근태 미입력·인정시간 미확정 상태를 표시한다.
- 휴가 예정일과 사유를 신청 초안으로 남기고 축약 신청서에서 확인할 수 있다. 실제 휴가 사용 확정·결재·근태 반영은 하지 않는다. 전달본의 사용 확인 후 서류 보완 흐름에 더해 미래 휴가 계획의 연결 방향을 검토하는 시안이다.

관련자와 분류 추가가 빠른 입력의 새 부담이 되지 않는지 함께 검토한다. 분류별 업무 건수만으로 평가 충족이나 증빙 완성을 판정하지 않는다.

## 두 번째 UX 수정: 선택 강조와 공통 날짜 탐색

- 선택된 검색 결과는 연보라 배경·진한 테두리·체크·선택됨 문구를 표시한다. 다시 누르면 해제된다. 아래 연결된 관련자는 진한 보라 배경의 칩으로 표시하고 개별 해제를 지원한다.
- 날짜 바를 화면 상단에 고정했다. 정확한 날짜 입력과 오늘로 이동, 이전/다음 버튼을 함께 둔다. 오늘/업무수행일지는 일 단위, 이번 주는 주 단위, 이번 달/출근부/휴가계획·신청서는 월 단위로 이동한다. 주간은 월요일~일요일의 전체 날짜 범위를 표시한다. 월 이동 시 말일을 넘으면 해당 월의 마지막 날로 맞춘다.
- 상위 메뉴는 오늘 / 이번 주 / 이번 달 / 서류로 정리했다. 업무수행일지 검토는 서류의 하위 화면으로 통합하고 별도 상위 메뉴는 제거했다. 세 서류 하위 탭도 날짜 바 안에 고정되며 직원과 기준 날짜를 유지한다.
- 일지 바로가기와 출근부의 날짜별 일지 보기도 서류 → 업무수행일지로 연결된다. 주간 날짜 띠는 일지 안에서 유지한다.
- 날짜별 화면에 집중할 수 있도록 업무 추가는 오늘 화면에 표시한다. 입력 중 다른 화면으로 이동해도 폼 값은 유지된다. 휴가 목록은 선택한 월로 좁혀 월간 탐색의 의미를 일치시켰다.

## 시안으로 결정할 것

- 빠른 추가의 내용·담당자와 접힌 선택 항목 구성이 충분히 간단한가?
- 오늘의 목록/계획/실행 배치가 기존 불릿저널의 장점을 유지하는가?
- 주간/월간에서 기한·예정·실적을 구분할 수 있는가? 더 중요한 요약은 무엇인가?
- 수행 기록에 짧은 결과를 남기는 정도가 일상 업무에서 감당할 만한가?
- 일지 검토가 다시 작성하는 일보다 실제로 가벼워지는가?

## 세 번째 UX 수정: 시각 강조와 수행 빠른 기록

- 상단 고정 날짜 바는 사이드바보다 진한 보라색 배경으로 강조하고, 활성 서류 탭은 더 진한 보라색으로 구분한다. 빠른 업무 추가 카드에는 보라 계열의 그림자를 보강했다.
- 오늘의 계획 카드는 오전 / 오후 / 취소 버튼을 표시한다. 오전·오후 선택은 입력창 없이 해당 계획의 날짜와 수행자를 기준으로 기록한다. 이미 같은 계획·수행자의 기록이 있으면 시간대만 변경하며 같은 시간대 재클릭으로 중복 생성하지 않는다. 수행 후 상세 내용은 실제 수행 카드의 내용 수정에서 보완한다. 업무 전체 완료와 일지 검토는 별도다.
- 계획 취소는 해당 계획을 배열과 화면·달력에서 제거한다. 원래 업무와 기존 수행은 유지되어 재계획할 수 있다.
- 내게 연결된 업무의 취소는 업무 목록/기한 표시와 연결 계획을 제거하고 기존 수행은 유지한다. 수행이 참조할 업무 정보는 메모리에 남긴다. 취소 직후 안내의 되돌리기로 업무와 계획을 복원할 수 있다.
- 업무 제목은 선택일 계획에 보라색, 선택일 수행에 초록색 형광펜 효과를 넣는다. 두 상태가 모두 있으면 수행 색을 우선하고 계획/수행 건수를 함께 표시한다. 다른 날짜에만 기록이 있으면 그 사실을 문구로 표시한다. 카드 전체 배경은 바꾸지 않는다.

## 네 번째 UX 수정: 컴팩트 입력·수행 취소·구성원 스티커

- 빠른 추가 카드의 최대 폭·내부 여백·컨트롤 간격을 줄이고 내용 입력과 관련자 검색을 왼쪽에 모았다. 관련자 검색은 PC에서 220px, 모바일에서 180px을 기준으로 줄어든다. 관련자 선택 배경은 연보라색으로 낮추고 체크/선택 문구와 테두리를 유지한다.
- 실제 수행 카드에 취소를 추가했다. 취소하면 수행 목록·일지·달력에서 빠지고 제목 강조와 계획 카드의 수행 표시도 갱신된다. 계획과 업무 전체 상태는 유지된다. 취소 직후 되돌리기로 기록을 복원할 수 있다.
- 주간/월간 전체 구성원 보기에서 기한·계획·실제 수행 카드의 좌상단 밖으로 일부 돌출되는 흰색 원형 스티커를 표시한다. 황 사회복지사 ㅎ, 김 사회복지사 ㄱ, 센터장 ㅅ을 사용하고 전체 이름은 툴팁/접근성 이름으로 제공한다. 미지정은 ?다.
- 전체 보기의 실제 수행은 하나의 합계 대신 기록별로 표시하여 실제 수행자를 구분한다. 기한은 담당자, 계획은 계획 소유자, 실제 수행은 기록의 수행자를 표시한다. 개인 보기에서는 스티커를 생략한다.
- 이번 수정에서 서류의 양식/흐름은 변경하지 않았다. 일지·출근부는 핸드오프의 기본 서식으로 먼저 생성하고 빈칸을 채우는 후속 구현이 필요하다. 현재 휴가 화면은 미래 계획을 보여주는 탐색 시안이며, 핸드오프의 **확인된 연차 사용일 → 날짜별 신청서 작성**과 다르다. 원형 흐름을 기본으로 복원하고 미래 휴가 계획은 분리할지 후속 설계에서 결정한다.

## 남겨둔 범위

알림 전송, 원문 분석, 자연어 날짜 해석, 반복 업무 자동 생성, 기존 데이터 이관, 인증·권한, 서버 저장, 실제 근태/휴가 승인·사용 관리, 정식 문서 확정/출력은 구현하지 않았다. 보기 대상 선택은 권한 체계가 아니다. 서류 미리보기는 축약 구조로 실제 제출 서식의 페이지·서명란을 재현하지 않는다.

근태/휴가 확인 방법, 최종 검토자, 타인 기록의 공개 범위는 추후 운영 규칙 확인이 필요하다. 센터장의 역할만으로 전체 수정/승인 권한을 확정하지 않았다.

## 검증

스크립트 문법과 메모리 내 상호작용 검사로 화면 전환, 업무 추가 후 담당자별 표시, 수행 기록과 전체 완료 분리, 시간대 확인과 일지 반영을 확인했다. 추가 검사로 관련자 임시 등록·중복 방지·분류/업무 연결, 월 경계의 일지 날짜 이동, 휴가 신청 초안과 근태 미확정 분리를 확인했다. 실제 브라우저의 렌더링·모바일 레이아웃·키보드/대화상자 동작은 별도 확인 대상이다.

두 번째 UX 수정에서는 관련자 선택/해제, 일·주·월 이동, 월말 보정, 직접 날짜 지정, 서류 세 탭의 유지, 일지 바로가기의 직원/날짜 맥락, 휴가 목록의 월 필터를 메모리 내 검사로 확인했다. 상단 고정 바의 실제 브라우저 배치와 스크롤은 미검증이다.

세 번째 UX 수정에서는 오전/오후 빠른 기록·중복 방지, 계획 삭제 후 수행 보존, 업무 취소 시 연결 계획/기한 제거와 되돌리기, 제목 상태 표시, 기존 화면/일지 이동을 메모리 내 검사로 확인했다. 그림자·색상 등 실제 렌더링은 미검증이다.

네 번째 수정은 수행 취소/복원·계획 보존·제목 강조 갱신, 전체 보기의 주간/월간 스티커와 수행자별 기록, 초성/전체 이름, 관련자 선택, 서류 경로 유지의 메모리 내 검사를 통과했다. 컴팩트 배치와 스티커 돌출 모양은 실제 브라우저에서 미검증이다.
