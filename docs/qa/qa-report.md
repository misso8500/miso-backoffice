# 미소 노인재가복지센터 백오피스 QA
## 2026-10-26 / 공동업무 항목 불편사항 건
### 1. 공동업무 항목의 수정, 삭제 건
- 만들어진 항목에 대해 보는 것이 정보가 너무 많이 들어있음
- 필요한 것은 근무 내용과 담당자, 업무 배정 여부, 실행 여부 등임
- 업무 계획-수행기록-전체완료 등에 대한 액션이 따로따로 나뉜 것 같이 느껴짐. 이 부분에 대한 대대적 개선 필요
  - 예시로는 투두리스트에서는 태스크를 한줄로 가볍게 생성하고, 생성한 것을 마감일자를 확인하고 오늘 할일에 배치했다면 계획했고, 거기에서 체크박스에 체크하면 간단히 완료되었음을 알 수 있음.
### 2. 공동업무 항목의 빠른 입력 폼 불편 건
- 공동업무 항목은 쉽게 작성하고, 작게 보이고, 빠르게 완료하고 수정해야 함
- 현재 작업 칸에서 입력하는 항목이 너무 크고 방대하게 느껴짐
  - 한 줄로 입력해서 업무를 전송하는 것은 편리함
  - 업무 분류와 기한 선택 부분이 조금 더 컴팩트해야 한다고 느껴짐
  - 수급자 선택과 연결 항목이 너무 거대함 조금 더 줄어들어야 함
  - 필요 시 전체 노출이 아니라 검색하는 항목만 남기는게 낫다고 판단됨
  - 가로 길이를 모두 쓰는 전제로 조금더 높이를 줄이는 방식으로 개선 필요(todolist와 비교하여 너무 큰 입력 공간)
### 3. 공동업무 항목 같이보기 항목의 시인성 개선 건
- 주간, 월간 보기의 시인성이 상당히 불편함
- 일단 컴포넌트의 크기가 상당히 큼. 이를 간단히 줄이고 사용자가 클릭 혹은 포커스를 통해서 크게 보여줄 수 있는 방식의 개선점이 필요하다고 생각됨
- 실제로 업무가 생성된 날과 마감일을 기준으로 하나의 업무가 언제 시작되었는지를 보는 것, 그리고 계획하였고, 실행한 날짜가 어떻게 다른지를 확인하고 싶은 것인데, 단계 별로 사용자가 진행하는 액션이 너무 많게 느껴짐
