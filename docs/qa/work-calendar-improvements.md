# 주간·월간 공동업무 UX 개선

## 이용 흐름

1~5분의 짧은 방문에서 업무를 찾고 처리할 수 있도록 일간과 동일한 빠른 입력, 완료 체크, 단일 상세 사이드바를 사용한다. 업무를 선택해도 현재 주간·월간 탭과 기준 기간은 유지한다.

- 큰 업무 카드를 제목·담당자·계획/수행/마감 표시의 작은 행으로 변경.
- 같은 날짜·같은 업무·같은 담당자의 기록만 합쳐 표시. 서로 다른 계획일·수행일·마감일은 각각 유지.
- 주간은 날짜별 목록, 월간은 날짜당 최대 3개 업무와 나머지 건수 표시. 더 보기를 누르면 해당 날짜의 전체 목록으로 스크롤.
- 업무 클릭 시 오른쪽 상세 하나만 표시. 여러 항목을 편집한 뒤 한 번에 저장.
- 달력에서 체크해 완료하고 되돌리기 가능. 수행 기록과 업무 전체 완료는 구분.
- 날짜 미정 업무에서 상세를 열어 계획에 배치. 수행 기록은 선택 날짜의 하단 패널에서 확인·수정.
- 주간·월간에서도 한 줄 업무 등록 지원. 저장 결과와 수행 변경을 달력에 갱신.
- 기존 색상 유지. 모바일 월간은 7열 요약, 주간은 날짜별 세로 목록. 상세는 오른쪽 사이드바로 표시.

## 회귀 검증

- `npm run build`
- `node --test tests/work-calendar-entries.test.mjs tests/work-calendar.test.mjs tests/work-journal.test.mjs tests/work-tasks-api.test.mjs`
- `node tests/work-calendar-ui.mjs`, `node tests/work-detail-ui.mjs`: playwright-core와 Chrome 필요. `WORK_UI_PLAYWRIGHT_MODULE`로 별도 설치된 모듈의 절대 경로, `WORK_UI_CHROME_PATH`로 브라우저 경로 지정 가능.
- 브라우저 테스트는 가상 데이터와 API 응답만 사용한다. 데스크톱·모바일에서 탭 유지, 상세 수정, 완료/되돌리기, 날짜별 표시, 더 보기, 단일 사이드바와 작업 상태 표시를 검증한다.
