# 계획일과 실제 수행일 분리

- 오늘 계획: 오늘 오전/오후 수행 버튼으로 바로 저장.
- 과거 계획: 오늘 수행, 계획일에 수행, 다른 날짜를 구분. 날짜를 표시한 입력 영역에서 오전/오후를 선택해 저장.
- 미래 계획: 계획일에 수행 버튼은 비활성화. 실제로 미리 처리했다면 오늘 또는 과거 날짜로 기록 가능.
- 계획일은 유지하고 수행의 실제 날짜만 저장. 업무 전체 완료 상태는 바꾸지 않음.
- 다른 날에 수행해도 원래 계획의 연결을 유지하며, 계획 아래에 실제 수행일과 수정 버튼 표시.
- 수행일·처리자·내용을 수정하거나 직전 저장을 되돌릴 수 있음. 버전 검사와 변경 이력 유지.

API는 계획 수행 요청의 선택적 `date`, 수행 수정의 선택적 `date`를 지원한다. 생략한 기존 요청은 기존 동작을 유지한다. 일간 응답의 `linkedExecutions`는 선택일 계획과 연결된 다른 날짜의 수행을 제공한다. 스키마 변경은 없다.

검증: 빌드, SQLite/Postgres 어댑터 및 API 테스트, `tests/work-actual-date-ui.mjs`의 데스크톱·모바일 브라우저 테스트. 브라우저 테스트 실행 환경은 `work-calendar-improvements.md` 참고.
