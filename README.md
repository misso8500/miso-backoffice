# Miso Backoffice Lite ERP System

## MVP 1.0
- 위 문서에서는 미소 노인재가복지센터에서 사용할 장기요양 관련 서비스를 통합형 ERP로 구축할 수 있는 기반 시스템 설계를 고안한다.

### 문제 상황의 정리
1. 수급자(고객) 관리의 데이터 트래킹과 관련 업무 자동화
    - 수급자의 기본 정보가 산재해 있어 확인하기가 어려움
    - 수급자의 기본 정보를 기반으로 계약 기간, 갱신 기간 등에 대한 정보를 지속적으로 기록하고 업데이트해야 하며, 이를 한 눈에 볼 수 없는 문제점이 있음
    - 1개월에 한 번 방문하는 라운딩 업무 시 어떤 내용의 가감이 있었는지, 통계적으로 어떤 점이 눈에 띄게 바뀌고 있는지 확인할 수 없음
2. 요양보호사(근로자) 급여 관리 데이터 트래킹과 관련 업무 자동화
    - 요양보호사의 근무 계약과 관련한 데이터를 한 눈에 볼 수 없음
    - 요양보호사의 근무 중 급여 제공 관련한 급여 대장을 기입할 때 정립된 시스템이 없어 수기 입력 중
    - 급여대장을 바탕으로 급여 명세서 자동 생성, 급여 대장 월 별 확인, 퇴직금 적립 등과 관련한 시스템의 부족으로 업무 수기 입력 반복 불편
