# miso-backoffice

미소 노인재가복지센터를 위한 백오피스 웹 프로젝트입니다.

이 프로젝트는 가장 작은 범위의 MVP에서 시작하지만, 이후 수급자 관리뿐 아니라 근로자, 근로계약, 임금, 근태, 고객 관리까지 확장되는 운영 시스템을 목표로 합니다.

## 프로젝트 방향

- 1인 개발을 전제로 한다.
- 개발을 진행하면서 학습 문서와 구현 문서를 함께 축적한다.
- 초기 MVP에서는 복잡한 분리 아키텍처보다 유지보수와 학습 효율을 우선한다.
- Python은 이번 프로젝트의 기본 스택으로 채택하지 않는다.
- 프론트엔드와 백엔드를 가능한 한 하나의 흐름 안에서 개발할 수 있는 구조를 우선 검토한다.

## 현재 MVP 범위

현재 단계의 핵심 목표는 수급자 관리 기능을 안정적으로 구현하는 것이다.

- 수급자 정보 등록, 조회, 수정, 삭제
- 담당 관리자 배정
- 담당자 기준 수급자 목록 확인
- 계약 만료일 기준 경고 표시
- 이름, 등급, 계약 상태 기반 검색과 필터

## 기술 선택 기준

이 프로젝트는 처음 배우는 기술이라도 다음 조건을 만족하는 방향을 우선한다.

- 학습 자료가 충분하고 국내외 레퍼런스가 많을 것
- 폼, 목록, 검색, 권한, 데이터 관리 같은 백오피스 패턴을 반복해서 확장하기 쉬울 것
- 1인 개발자가 화면과 서버 로직을 한 흐름으로 다루기 쉬울 것
- 추후 도메인이 늘어나더라도 구조를 크게 뒤엎지 않아도 될 것

## 현재 권장 스택 방향

현 시점의 우선 고려 방향은 다음과 같다.

- 프레임워크: Next.js
- 언어: TypeScript
- 데이터베이스: PostgreSQL
- ORM: Prisma
- 인증: Auth.js

이 조합은 MVP를 빠르게 만들 수 있으면서도, 이후 근로자/계약/임금/근태/고객 관리처럼 데이터 중심의 관리 페이지를 같은 패턴으로 확장하기 좋다.
